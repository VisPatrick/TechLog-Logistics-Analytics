# 📊 Sistema de Análise Logística da Distribuidora TechLog

## Objetivo

Desenvolver uma solução de Business Intelligence para monitoramento dos processos logísticos da Distribuidora TechLog, utilizando MySQL, Python e Power BI.

---

## Tecnologias Utilizadas

- MySQL
- Python
- Pandas
- NumPy
- Power BI

---

## Fluxo do Projeto

Banco de Dados MySQL
↓
ETL Python
↓
Tratamento dos Dados
↓
Exportação CSV/Excel
↓
Dashboard Power BI

---

## Indicadores Desenvolvidos

- Total de Pedidos
- Total Expedidos
- SLA de Entrega (%)
- Eficiência de Entrega (%)
- Lead Time Médio
- Taxa de Atraso (%)
- Total de Avarias
- Taxa de Avarias (%)
- Produtos Críticos
- Giro Operacional

---

## Estrutura do Dashboard

### Visão Executiva
Panorama geral da operação logística.

### Recebimento
Monitoramento de avarias e qualidade dos recebimentos.

### Estoque
Controle de estoque, produtos críticos e giro operacional.

### Expedição
Análise de entregas, SLA e desempenho logístico.

### Relatório Gerencial
Resumo executivo, achados e recomendações.

---

## Principais Insights

- Mais de 500 expedições analisadas.
- Mais de 250 mil itens expedidos.
- Apenas um produto em situação crítica de estoque.
- Mouse Gamer RGB apresentou maior volume de avarias.
- Monitoramento completo de SLA e Lead Time.
